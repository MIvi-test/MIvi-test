## Featured Projects

### TaskFlow

[Repository](https://github.com/MIvi-test/taskflow)

Учебное full-stack приложение для изучения DevOps-практик, контейниризации и эксплуатации сервисов.

Используемые технологии на текущий момент(v1.3):

- Docker Compose
- FastAPI
- PostgreSQL
- reverse proxy на базе Caddy
- Prometheus
- Grafana
- node_exporter

В проекте изучаются:

- разделение frontend и backend;
- запуск нескольких сервисов;
- взаимодействие контейнеров через Docker network;
- healthcheck;
- reverse proxy configuration;
- сбор application metrics;
- подключение Prometheus и Grafana;
- ограничение доступа к служебным интерфейсам.

Frontend был создан с помощью Qwen Coder и используется как прикладная нагрузка для изучения backend infrastructure, containerization и эксплуатации сервиса.

### CPU Schedulers Compare

[Repository](https://github.com/MIvi-test/CpuSchedulersCompare)

Симулятор и инструмент сравнения алгоритмов планирования процессов в операционных системах.

Проект позволяет анализировать:

- Waiting Time;
- Turnaround Time;
- Response Time;
- CPU Utilization;
- распределение процессов по времени;
- Gantt chart для работы планировщиков.

Frontend и визуальная часть проекта были созданы с помощью Qwen Coder. Основной учебный фокус проекта — Operating Systems, CPU scheduling algorithms и анализ поведения планировщиков.

### Labirit

[Repository](https://github.com/MIvi-test/labirit)

Исследовательская программа в рамках курсовой работы на языке C для генерации, анализа и тестирования лабиринтов.

Проект включает:

Проект помогает развивать навыки работы с C, алгоритмами, тестированием и performance analysis.
